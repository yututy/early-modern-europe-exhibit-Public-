# 问卷 · 线上历史展访问偏好（P4-02）

> 用途：项目四设计研究。板上中栏为**模拟样本结果**（便于先铺版）；若需真实数据，用本卷原题重发即可替换数字。  
> 建议样本：设计 / 人文相关青年，n≈40–60。

## 筛选

- 年龄 18–30  
- 近一年有过至少一次「看展览 / 逛博物馆线上展 / 玩历史向游戏」任一经历（可放宽）

## 题目（英文可上板；括号内为中文说明）

1. In the past year, have you visited an **online museum or history exhibition**?  
   （过去一年是否逛过线上博物馆/历史展？）  
   Yes / No / Not sure

2. If an online history exhibit is dense, what visit length feels acceptable?  
   （内容较密时，可接受时长？）  
   ≤5 min / 5–15 min / 15–30 min / 30+ min

3. Which format do you prefer for learning a historical theme online? (pick one primary)  
   （线上学历史主题，首选形态？）  
   Endless browse (catalogue) / Room-like walk / Short interactive / Short game / Short film/video

4. Would you try a **≤2-minute mini-game** inside an exhibition if rules ≤3?  
   （馆内嵌 ≤2 分钟、规则≤3 条的小游戏，愿不愿意试？）  
   Yes / Maybe / No

5. For abstract topics (e.g. sovereignty / empire), which medium feels clearest?  
   （抽象主题如主权/帝国，哪种媒介更清楚？）  
   Text labels / Diagram / Interactive / Short film

6. What makes you **trust** an online history exhibit? (multi-select, max 3)  
   （信任点，最多选 3）  
   Named scholarly book / Museum brand / Clear sources / Visible authors / Nice visuals only

7. Main frustrations with online history/culture platforms you know? (multi-select)  
   （对已知线上文史平台的不满？）  
   No clear end / Endless scroll / Walls of text / Feels like a game not an exhibit / Hard to remember anything / Other

8. Open: In one sentence, what would make you finish a short online history visit?  
   （开放：怎样会让你把一个短线上史展逛完？）

---

## 模拟结果（n=48 · 用于 P4-02 中栏 · 非正式抽样）

| 指标 | 模拟结果 |
|------|----------|
| 逛过线上博物馆/史展 | **68%** |
| 可接受时长落在 ≤15 min | **54%**（另 28% 选 15–30） |
| 首选「像房间一样走」 | **61%** |
| 愿试馆内短小游戏 | **47%** Yes + **31%** Maybe |
| 抽象政治主题偏好短片/影像 | **39%**（交互 27%，图解 22%） |
| 信任点含「点名学术书」 | **72%** |
| 痛点：没有终点/无限刷 | **52%** |
| 痛点：长文墙 | **48%** |
| 痛点：太像游戏、不信任 | **41%** |
| 痛点：没有清晰路径 | **44%** |

### Design takeaway（由模拟结果推出）

- 把访问设计成 **≤15 分钟、有大门有终点的短路径**  
- **三厅 = 三种短媒介**，按主题选，不做成开放世界长游戏  
- 展签/门厅露出 **Rice & Grafton** 等书脊，建立信任  
- 军事厅小游戏：规则≤3、时长≤2 分钟，避免「整馆变游戏」
