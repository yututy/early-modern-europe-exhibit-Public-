# 提示词 · P4-01 右栏「文献综述」（史学）

> 用途：交给写手 / 查资料 AI，产出**早期现代欧洲（1460–1559）史学文献综述**短文。  
> 版面：作品集 **P4-01 开篇** 右侧约 **1/3**（栏目标题：`LITERATURE REVIEW` 或 `HISTORIOGRAPHY`）。  
> **不是**设计研究、不是媒介先例、不是「本项目缺口」——那些放 **P4-02**。

---

| 要写（P4-01 右栏） | 不要写（留给 P4-02） |

| 以 Rice & Grafton 为脊柱书的定位 | 「一门三厅」「≤15 分钟」产品切口 |

## 1. 任务一句话

请为互动媒体作品集写一篇**极短史学文献综述**（英文主交付 + 中文对照），对象是时段 **1460–1559（Early Modern Europe / 早期现代欧洲的「奠基」世纪）**，供 Figma 一栏扫读，不是学期论文。

---

## 2. 必读脊柱（不得架空）

| 项 | 内容 |
|----|------|
| 中文书 | 《现代欧洲史 01：早期现代欧洲的建立 1460—1559》 |
| 作者 | 尤金·赖斯、安东尼·格拉夫顿（Eugene F. Rice Jr., Anthony Grafton） |
| 英文 | *The Foundations of Early Modern Europe, 1460–1559* |
| 卷内对应 | 军事偏 Ch.1「新型战争」；经济 Ch.2；政治 Ch.4；改革 Ch.5–6 **只作权力/国家形成延伸，不单开宗教专章综述** |

**综述必须回答：** Rice & Grafton 把这一百年写成怎样的「同时性奠基」？你的综述如何把后续二手文献挂在这条脊柱上？

（若写手无纸书：可用可靠书目页 / 图书馆记录确认书名与时段；**禁止伪造页码与伪引文**。）

---

## 3. 辅线文献（允许写「脉络」，禁止硬编摘句）

按三条线组织，每条写清：**代表问题 / 代表作者或辩论 / 与 1460–1559 的关系 / 使用限度**：

1. **军事史**  
   - Geoffrey Parker 及相关 *Military Revolution* 辩论（棱堡、火器、财政—军事国家等）。  
   - 说明：学界有争议 → 综述里写成 **debate**，不要写成定论。  
   - Michael Howard：可作战争史谱系书目；**不要伪造逐条摘句**（找不到可核对引文就只列书目角色）。

2. **政治思想 / 国家形成**  
   - Jean Bodin 与 sovereignty（主权最高、持久；仍受神法/自然法约束）。  
   - 稳链参考：https://plato.stanford.edu/entries/bodin/  
   - 可点到查理五世复合君主国、意大利战争（1494–1559）作为政治史背景，但以**文献问题**为主，不要堆事件年表。

3. **经济 / 商业与金融**  
   - 紧扣 Vol.01 Ch.2 问题域：商人精英、矿冶、人口与城市、putting-out（出差制）等。  
   - 专名可出现：Fugger、Antwerp、Medici（作文献—史实锚点，不是旅游介绍）。  
   - 可补充 1–2 个该领域常见二手脉络（须可核书目）；**不要 DOI 堆砌、不要假页码**。

**改革：** 最多用一小段说明「教权—王权 / 改宗与领地权力」在史学中常被并入国家形成叙事；**不要**写成第四条与三厅平行的完整宗教史综述。

---

## 4. 输出结构（严格按此小标题）

英文交付，小标题可用下列英文（便于直接上板）：

1. **Scope**（2–3 句）— 综述覆盖什么时段、什么问题，明确「早期现代奠基世纪」而非整个中世纪。  
2. **Spine**（4–6 句）— Rice & Grafton 的核心主张与叙事结构（同时性：印刷 / 战争 / 经济 / 国家）。  
3. **Military historiography**（4–6 句）— Parker 辩论 + 限度。  
4. **State & political thought**（4–6 句）— 主权国家史学 + Bodin。  
5. **Economy & commercial expansion**（4–6 句）— 商业—金融—生产组织文献问题。  
6. **Synthesis**（3–5 句）— 三条线如何共同支撑「同时性」阅读；点出仍开放的争论（1–2 个即可）。  

**不要**写：Design opportunity / Gap for interactive media / Precedents / Tech stack。

## 5. 篇幅与语气

| 项 | 要求 |
|----|------|
| 英文正文 | **380–520 words**（适合一栏 12pt 扫读；可略超，但不要写成长文） |
| 中文对照 | 全文翻译，供沟通；上板以英文为准 |
| 语气 | 学术综述：客观、谨慎、有「辩论/限度」；禁止营销腔 |
| 人称 | 第三人称；不要 “our project / we will build” |

---

## 6. 引用与诚实规则（硬性）

1. **禁止伪造**：页码、DOI、期刊卷期、伪引文一律不要。  
2. **允许类型**：Wikipedia 概念页、Stanford Encyclopedia、剑桥等出版社书目页、可打开的书评/词条；宁缺毋假。  
3. 文末附 **Reference list（5–10 条）**：书名/作者/年份（若可知）+ 可核 URL；标清哪些是「脉络概述」、哪些是「已核对引文」。  
4. Howard：若无可靠摘句来源 → 写 “bibliographic only”。  
5. 与 Rice & Grafton 冲突时，**以脊柱书问题框架为准**，二手文献作对照而非推翻展览时段设定。
