## 1 · 政治厅（最先制作 · TouchDesigner → mp4）

### 1.1 厅门签

- **标题**：看见主权  
- **副句**：谁立法、谁收税、谁指挥常备武力——早期现代国家把这些权力从封建碎片收回到君主。  
- **成片对位名**：查理五世的复合帝国（西班牙称**查理一世**）  
- **进厅导语**：本厅成片点亮的，不是抽象「民族国家」，而是**同一家族名下的多块领地**：以卡斯蒂利亚—阿拉贡为基座的西班牙君主权，叠上低地、意大利与奥地利核心。他在西班牙是查理一世，在神罗是查理五世——主权如何在这种复合帝国里被立法、代理人与宣传「看见」，是本厅主线。  
- 来源：精读 §4.1–4.5（书 p.164–197）；三厅文字 A/F-10

### 1.2 政治厅主视觉（探光交互 · 取代纯成片）

**概念**：Dark map → light finds the empire → title locks in  
**现行做法（网页）**：鼠标/触控手电筒；依次照亮伊比利亚、低地、意大利、奥地利四处；四处都找到后出现标题 `One family, many territories`。成稿见 `web/src/main.js` 的 `bindEmpireFlash`。

**TD 可选**：当面演示仍可用 `politics_flashlight.toe` 做实时探光；不必再录 `politics.mp4` 作为网站主视觉。若要答辩录屏，可直接录网页交互。

| 要素 | 内容 |
|------|------|
| 画面 | 暗地图 + 跟随光标的柔光 |
| 目标点 | 伊比利亚 / 低地 / 意大利 / 奥地利核心 |
| 解锁 | 4/4 后标题淡入 |
| 深读 | 右侧展签 + 下方读墙不变 |

成片命题不变：**复合帝国如何被「看见」**。

### 1.3 成片旁展签（点选切换下方读墙 · 3 条）

**交互**：
- 右侧三点展签只保留标题 + 导语；点击后，下方读墙换成该主题。
- 读墙内左右滑动 / 点箭头 / 点圆点时，**标题 + 两段正文 + 配图整屏一起换**（不再只换底部图）。
- 每个主题 3 屏；每屏各写两段贴近卷一语气的正文。页面**不显示** §/页码出处。

1. **同一家族，多块领地**  
   **导语**：成片点亮的西班牙、低地、意大利与奥地利核心，同属一人名下：西班牙的查理一世，也是神圣罗马帝国的查理五世。  
   **三屏**：欧洲棋盘总图（加长查理一世叙述）→ 双像对照（西班牙查理一世坐像 / 神罗查理五世帝像）→ 帝国如何聚拢（继承、联姻与 1519 帝选）  
   核对：§4.4–4.5；三厅文字 F-10

2. **博丹的主权**  
   **导语**：主权被说成最高、绝对且持久；可立法、可废法。但它并非无法无天——神法与自然法仍勒住君主的缰绳。  
   **三屏**：双头鹰与帝国名义 → 王意落到地方（时辰书 / 代理人）→ 绝对却非空白支票  
   核对：§4.1、§4.3；三厅文字 B-2

3. **1494 之后的欧洲棋盘**  
   **导语**：查理八世一脚踏进意大利，半岛的邦联式自主被拖进更大的欧洲战争；此后半个世纪，哈布斯堡、瓦卢瓦与奥斯曼轮番坐庄。  
   **三屏**：会用炮的王权战争 → 低地城市与信贷 → 印刷把争论甩进政治  
   核对：§4.5；§1.3–1.4（帕维亚）；三厅文字 F-11

成稿全文见 `web/src/main.js` 的 `themes[].slides`。

## 2 · 经济厅（总账过账 · 交互贯穿）

### 厅门签

- **标题**：扩张的引擎  
- **副句**：16 世纪上半叶的繁荣里，真正拉开尺度的是商人—银行家与矿冶帝国。  
- 路由：`#/economy`  
- 来源：§2.1–2.2

### 结构与交互（一本总账走完全厅）

| 层 | 做法 |
|----|------|
| 隐喻 | 打开的总账：左页流水、右页待办 |
| 节奏 | 每笔：**过账 → 盖章 → 正文 + 专项交互**；章末 **书卷翻页** |
| 体量 | 三册 × 三笔 = **九笔** |
| 终幕 | `Private credit, public power` + 帝国棋盘收束图 |
| 成稿 | `web/src/economy-ledger.js` |

**分帖交互**：1.1 人口表 · 1.2 冶炼三步小游戏 · 1.3 枢纽点选 · 2.2 行业名册 · 2.3 分包链+利弊 · 3.2 弗罗林分期入账 · 3.3 三印复习。3.1 改为雅各布生平；1519 数字口径见帖内注释（约 543,385 / 总额约 85 万量级）。

与政治厅差异：无探光地图、无旁签轮播；整厅操作都在账册内完成。

### 2.1 三册九笔

1. **第 I 册 · 繁荣的底盘** — 人口/城市 → 矿冶产业 → 安特卫普枢纽  
2. **第 II 册 · 商人—银行家** — 美第奇尺度 → 办公室簿记 → 出差制  
3. **第 III 册 · 矿冶接到帝选** — 富格尔帝国 → 1519 约 54.3 万 → 私人信贷/公共权力  

核对：§2.1–2.2 p.065–072

### 2.2 操作说明（观众）

1. 右页读「待过账单」，点 **过账入册**（左页出现分录）。  
2. 点 **盖章确认**（印章落下），展开该笔长文与配图。  
3. **继续下一笔**；每册第三笔后 **开新页**。  
4. 九笔后锁册，可进军事厅。左页已入账分录可回看。

## 3 · 军事厅（读墙已加厚；军制卡小游戏已上线）

### 厅门签

- **标题**：新型战争  
- **副句**：1450–1550，火药与步兵改写战场，也改写谁垄断武力。  
- 路由：`#/military`  
- 来源：§1.1 p.015

### 交互（读墙已上线）

体量对齐政治厅：左侧 **3 主题路径**，右侧每主题 **3 帖轮播**（共 9 帖长文 + 配图）；探访满 3/3 显示「到站」。成稿见 `web/src/main.js` 的 `militaryThemes`。

| 主题 | 帖数要点 | 主配图 |
|------|----------|--------|
| 战争艺术改写 | 印刷类比；人马合甲；矛墙；**装备换代（半甲/戟）** | 甲 / 人马甲 / 战图 / 双像 |
| 炮与要塞失效 | 巨炮；围攻潮；步兵实质；**围攻 vs 野战两种形式** | 丢勒炮 / 围攻图 / 半甲 / 炮 |
| 矛线、火枪与王权 | 莫拉特；矛火咬合；双重后果；**编制合成** | 战图 / 枪×戟 / 亨利甲 / 亨利甲 |

文案按赖斯/格拉夫顿手法；读墙侧重**战争形式变化 + 武器装备更新**。

### 小游戏：对撞局 → 读墙 → 战争与经济（已上线）

**路径**

1. **进厅即见对撞局**：四幕选军制（战争形式）；错选仍前进，教学向。  
2. **通关后下滚读墙**：3 主题 × 4 帖。  
3. **到站或通关按钮** → 第二局 **「王国的账本」**：五波编制 / 国库 / 贵族，不以杀敌计分。  
4. 读墙到站可进 **结束页** `#/end`；不强制串联经济厅。

（旧稿「五幕 + 装备二层」已由账本局取代，不再实现装备点选层。）

### 小游戏规则（≤3 条，局内可见）

1. **炮**：旧石墙扛不住重炮——围攻被重新计时。  
2. **矛**：纪律化矛墙挡住甲骑冲击。  
3. **火**：火枪要咬合矛线；能编组者，是王权战争。  

来源：§1.3–1.4 p.017–022

### 结束回扣句（胜负后固定展示）

> 1476 莫拉特：被讥为「吃奶酪的农民」的瑞士矛阵，击败勃艮第骑士。武器让战争同时**王权化**与**平民化**。  

来源：§1.3 p.018；§1.4 p.021–022

### 设计红线

- 不模拟屠杀得分；不种族化敌人；不宗教善恶二元。  
- 单局 ≤2–3 分钟。
