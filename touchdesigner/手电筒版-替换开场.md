# 政治厅开场 · 手电筒版（取代旧「分段点亮」）

概念不变：**Dark map → light finds the empire → title locks in**  
做法升级：用手势（或鼠标）控制柔光手电筒，在暗地图上「找到」复合帝国。

工程建议另存：`politics_flashlight.toe`（勿直接覆盖旧工程，方便回退）  
最终仍导出：`assets/politics.mp4`（1280×720）→ 网站政治厅自动用新片

对照教程气质：[手势交互手电筒 | TouchDesigner](https://www.bilibili.com/video/BV1vMBbYrERN/)  
插件：[MediaPipe for TouchDesigner](https://github.com/torinmb/mediapipe-touchdesigner/releases)

## 视觉规格（保持艺术感）

- 底图：现有帝国总图（`assets/politics/map_empire.png` 或 `media/` 里那张）
- 全图默认压暗（像未点亮的展柜）
- 光斑：大、软、暖金（不要霓虹蓝紫）
- 手移动 → 光斑移动；地图只在光内变亮
- 约 30–40 秒后标题淡入：`One family, many territories`
- 首尾近黑，便于网页循环

建议扫光路径（录制时跟着走）：

```text
全黑 → 伊比利亚（停 2–3s）→ 低地 → 意大利 → 奥地利 → 略拉开看全图 → 落字 → 缓暗
```

## 节点链路（核心）

### 方案 1 · 先通链路（推荐：鼠标当手电筒）

不装 MediaPipe 也能先做出「高级感成片」：

```text
moviefilein MAP
  → level DARK          （压暗底图）
  → multiply LIT        （× 光蒙版）
       ↑
  circle SPOT（大、软边）
    → transform HAND    （Translate 绑鼠标或手拖）
    → level WARM        （略偏暖黄）
  → over TITLE          （后段叠字）
  → moviefileout
```

操作：
1. `DARK`：Brightness ≈ 0.25–0.4（很暗）
2. `SPOT`：Radius 大、Softness 高；颜色暖白/浅金
3. 录制时慢慢拖 `HAND` 的 Translate，沿「伊比利亚→低地→意大利→奥地利」
4. 后 8–10 秒把标题 Opacity 从 0 拉到 1
5. Movie File Out 录 30–45 秒 → 覆盖 `assets/politics.mp4`

### 方案 2 · 教程同款（摄像头手势）

在方案 1 通了之后再加：

1. 下载 MediaPipe 插件 Release，拖入 `MediaPipe.tox`
2. Video Device In → MediaPipe（Hand）
3. 取食指指尖（或 pinch 中点）XY → 驱动 `HAND` 的 Translate
4. 实时演示时：手移光移；录成片时同样扫一遍路径即可

手势不稳时：对 XY 加 **Lag / Filter CHOP**（平滑），光斑会立刻更「贵」。
