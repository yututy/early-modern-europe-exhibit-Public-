## 第 1 关 · 安装 TouchDesigner

1. 打开浏览器，进入：https://derivative.ca/download  
2. 下载 **Windows** 版 TouchDesigner  
3. 安装：一路 Next  
4. 打开软件。若要选许可证：
   - 有学生邮箱 → 可申请 Educational  
   - 否则选 **Non-Commercial（免费）** 即可  

### 免费版记住一句

导出分辨率用 **1280 × 720**，不要用 1920。网站一样清楚。

### 过关标准

能看到 TouchDesigner 主界面（中间有网格网络、右边有参数面板）。

3. 或点节点右下角预览旗标

## 第 3 关 · 暗地图 + 手电筒（核心）

我们要做三样东西：

1. 把地图压暗  
2. 做一盏大而软的暖光圆  
3. 让「暗地图 × 光」= 只有光里是亮的  

### 3.1 压暗地图

1. Tab 搜索：`level` → 选 **Level**（TOP）→ 得到 `level1`  
2. 接线（很重要）：
   - 用鼠标从 `moviefilein1` **右侧小圆点**拖一条线到 `level1` **左侧小圆点**  
3. 选中 `level1`，右侧改：
   - **Brightness** 拖到大约 `0.30`（很暗）  
   - **Contrast** 大约 `1.15`  

按 **U** 看 `level1`：地图应明显变暗。

### 3.2 做光斑圆

1. Tab 搜索：`circle` → **Circle** TOP → `circle1`  
2. 选中 `circle1`，右侧大致设：
   - **Radius** 先试 `0.35`～`0.45`（偏大）  
   - **Softness** 尽量高（很糊的边缘，不要硬边）  
   - 颜色：略暖的浅黄白（不要纯蓝光）  

预览应是一个柔和亮圆，周围黑。

### 3.3 让光可以拖动

1. Tab 搜索：`transform` → **Transform** TOP → `transform1`  
2. 接线：`circle1` → `transform1`  
3. 选中 `transform1`，找 **Translate** 的 X / Y  
4. **用鼠标慢慢拖 X、Y**，预览里圆应该会移动  

> 录视频时你就这样拖：从西班牙一带 → 低地 → 意大利 → 奥地利。

### 3.4 暗地图乘上光（手电筒效果）

1. Tab 搜索：`multiply` → **Multiply** TOP → `multiply1`  
2. 接线（两条）：
   - `level1`（暗地图）接到 `multiply1` 的一个输入  
   - `transform1`（光）接到 `multiply1` 的另一个输入  
3. 选中 `multiply1` 看预览：

**应该是：黑暗里，只有光圆扫过的地方地图变亮。**

如果整屏很怪：
- 检查两条线是否都接到 `multiply1`  
- 把 `circle1` Softness 再加大  
- 把 `level1` Brightness 再略降

### 过关标准

拖 `transform1` 的 Translate，光在暗地图上移动。回我：「第 3 关好了」。

## 第 4 关 · 加标题字

1. Tab 搜索：`text` → **Text** TOP → `text1`  
2. 参数：
   - **Text**：`One family, many territories`  
   - Font：Arial / Times New Roman 均可  
   - Font Size：先试 `36`～`44`  
   - 颜色：暖白（略黄，别刺眼纯白）  
3. Tab 搜索：`over` → **Over** TOP → `over1`  
4. 接线：
   - **下面层（背景）**：`multiply1`（手电筒画面）  
   - **上面层**：`text1`（字）  
5. 若字看不见：把两根输入对调，或加大字号  

录制时建议：**前 25 秒可以不接字**（或把 Text 的透明度/不用 Over），**最后 10 秒再叠字**。  
0 基础最简单做法：整段都带字也可以，先能导出再说。

### 过关标准

预览里是「手电筒地图 + 一行英文」。回我：「第 4 关好了」。

## 第 5 关 · 录成成片并挂到网站

### 5.1 接导出节点

1. Tab 搜索：`movie file out` → **Movie File Out** → `moviefileout1`  
2. 接线：`over1` → `moviefileout1`  
3. 选中 `moviefileout1`，设置：
   - **File** 存为：

`D:\并没有什么用的文件\作品集申请\项目四——现代欧洲线上展\assets\politics.mp4`

   - Codec：优先 **H.264**（没有就按默认，再转也行）  
   - 分辨率：**1280 × 720**

### 5.2 怎么录（表演一次即可）

1. 点 **Record / 开始录制**（按钮在 Movie File Out 参数里）  
2. 用约 **35–40 秒** 完成下面动作：
   - 开头 1–2 秒：光在画面外或很暗  
   - 光移到**伊比利亚（西班牙）**停 2–3 秒  
   - 移到**低地（北欧沿海）**停一下  
   - 移到**意大利**停一下  
   - 移到**奥地利一带**停一下  
   - 光略放大/移开一点，让人感觉看见「整盘棋」  
   - 最后几秒：确保标题在画面上  
   - 结尾 1 秒偏暗  
3. **停止录制**  
4. 去 `assets` 文件夹，双击 `politics.mp4` 用播放器看

### 5.3 在网站里看

1. 若本地预览已开：打开 http://127.0.0.1:5173/#/politics  
2. 没有的话在项目里运行：

```text
cd web
npm run dev
```

3. 强刷浏览器（Ctrl+F5），看政治厅视频是否换成新片

### 过关标准

`politics.mp4` 能播，网站政治厅能看见手电筒扫地图。回我：「成片好了」。

## 你现在的网络应该长这样

```text
moviefilein1 (地图)
    → level1 (压暗)
         ↘
          multiply1 → over1 → moviefileout1
         ↗              ↑
circle1 → transform1    text1
(光斑)    (拖动位置)     (标题)
```

---

## 常见卡点（先看这里）

| 现象 | 怎么办 |
|------|--------|
| 找不到节点 | 按 Tab，用英文搜 `movie` / `level` / `circle` / `multiply` / `text` / `over` |
| 线连不上 | 一定从节点**右侧输出**拖到另一节点**左侧输入** |
| 全黑 | `level1` 太暗；或 Multiply 只接了一根线 |
| 全亮没手电筒感 | Softness 太低；或没走 Multiply，误用了 Add |
| 字被切掉 | Font Size 改小；或分辨率设为 1280×720 |
| 网站还是旧片 | 确认覆盖的是 `assets/politics.mp4`，浏览器 Ctrl+F5 |
