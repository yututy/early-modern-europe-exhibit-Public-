# 政治厅开场片 · 节点清单（约 40 秒）

概念：**Dark map → light finds the empire → title locks in**  
工程：`politics_sovereignty.toe`  
导出：`assets/politics.mp4`（1280×720）

---

## 最终链路（从左到右）

```text
moviefilein1 (地图)
    → transform1 (慢推近)
    → level1 (压暗)
    → multiply1 (× 光蒙版)
         ↑
      over_light (或直接 multiply)
         ↑
circle1 / ramp → transform2 (光慢慢移动)
    → over_title (叠字)
         ↑
      text_main (+ 可选 text_sub)
    → moviefileout1
```

零基础可先做成简化版（也能很精致）：

```text
moviefilein1 → transform1 → level1 → over1 ← text_main
                                         → moviefileout1
```

下面先写**简化精致版**（推荐你先做这个）；通了再加「光扫过」。

---

## A. 简化精致版（必做）

### 1. 地图
- 节点：`moviefilein1`
- File：`media/map_charles_v_empire.png`

### 2. 慢推近
- 新建 **Transform TOP** → `transform1`
- 接线：`moviefilein1` → `transform1`
- 参数（先手动）：
  - **Scale** 从 `1.0` 慢慢拖到约 `1.08`（录制这 40 秒里你手慢慢拖也行）
  - 或只改 **Translate Y** 轻微上移 `0 → 0.02`

> 不会自动动画也没关系：录的时候用手慢慢拖 Scale，看起来就是推镜头。

### 3. 压暗（精致感关键）
- 新建 **Level TOP** → `level1`
- 接线：`transform1` → `level1`
- 试这些值（按观感微调）：
  - **Brightness** ≈ `0.55–0.7`（偏暗）
  - **Contrast** ≈ `1.1–1.2`

### 4. 主标题
- **Text TOP** → `text_main`
- Text：`One family, many territories`
- Font：Arial（或 Helvetica）
- Font Size：约 `36–44`
- Align：Horizontal Center，Vertical 可略偏下
- 颜色：暖白（别纯 #FFF；略黄灰更好）

### 5. 叠加
- **Over TOP** → `over1`
- **Input 下面/Fixed**：接 `level1`（地图）
- **Input 上面**：接 `text_main`
- 若字看不见：对调两根线，或把字 Size 加大

### 6. 导出
- **Movie File Out** ← `over1`
- File：`assets/politics.mp4`（或先 `.mov`）
- Record **On** → 录满约 **40 秒** → **Off**
- 开头结尾各留约 1 秒「几乎全黑」更好循环（可把前 1 秒 Brightness 更低）

---

## B. 加分：光扫过（可选）

在 `level1` 和 `over1` 之间插入：

1. **Circle TOP**（或 Ramp）  
   - Softness / Edge 尽量柔  
   - Scale 做大，像一盏柔光  
2. **Transform** 控制这个圆，录制时从左慢移到右  
3. **Multiply** 或 **Matte**：让地图只在光里更亮  

做不出就跳过；简化版已经够开场。

---

## C. 片尾小字（可选 · 最后 8 秒）

再建 `text_sub`：

`Seeing Sovereignty · 1460–1559`

字号更小（约主标题 55%），放在更下方。  
录到后段再把 `text_sub` 接到第二个 Over；前段可以不接（或 Opacity 从 0 拉到 1——手动拖也行）。
