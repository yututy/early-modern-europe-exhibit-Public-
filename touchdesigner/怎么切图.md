## 思路（重要）

不要切成「碎纸片随便叠」。正确做法是：

**每一块 PNG 都和整图一样大**，只在自己那片领地有像素，其余透明。  
这样进 TD 时全部叠在一起，位置天然对齐；动画只做「从外滑到原位」。

我们拆 **4 大块**（够表达 “many territories”，不会做爆）：

| 文件 | 含义 |
|------|------|
| `00_map_dim_base.png` | 暗底整图（垫底，一直很淡） |
| `01_iberia.png` | 伊比利亚（西/葡一带） |
| `02_low_countries.png` | 低地 / 尼德兰一带 |
| `03_italy.png` | 意大利一带 |
| `04_austria_core.png` | 奥地利 / 神罗核心一带 |

## 方法 A · 用已生成的块（推荐）

文件夹已有：

`touchdesigner/media/pieces/`

你在 TD 里：

1. 建 5 个 **Movie File In**，分别选上面 5 个 PNG  
2. 底层：`00_map_dim_base`  
3. 其上依次 Over：`01`→`02`→`03`→`04`  
4. 每个领地块前加 **Transform**：开场时 Translate 偏出画面，录制时拖回 `0,0`（或从 Opacity 0→1）  
5. 最后再 Over 标题：`One family, many territories`  
6. 录约 40 秒 → `assets/politics.mp4`

顺序建议出场：  
`01 伊比利亚 → 02 低地 → 03 意大利 → 04 奥地利核心 → 标题淡入`

## 方法 B · 自己在 PS / 剪映重切（想更贴国境线时）

1. 打开 `00_map_full.png`（同目录，已裁掉页边）  
2. 新建图层，用套索/钢笔沿 **斜线影线 = 西班牙哈布斯堡**、**竖线 = 奥地利** 等大致圈出 4 区（不必完美）  
3. 每区复制到新文件：画布尺寸 = 整图宽高，区外删除/透明，导出 PNG  
4. 命名同上，覆盖 `pieces/` 里对应文件  

图案是影线不是纯色，**不要用魔棒指望一次选干净**；矩形大块或粗套索足够动画用。

---

## 时间轴（约 40 秒）

| 秒 | 画面 |
|----|------|
| 0–2 | 黑 / 只有暗底 |
| 2–8 | 01 滑入 |
| 8–14 | 02 滑入 |
| 14–20 | 03 滑入 |
| 20–26 | 04 滑入 |
| 26–34 | 合成完，略停 + 极慢推近 |
| 34–40 | 标题淡入，近黑收 |

字不要闪白，用约 1 秒淡入。
